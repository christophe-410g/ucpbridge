# Signaler une faille de sécurité

UCP Bridge pour PrestaShop manipule des paniers, des paiements et des comptes clients. Si vous trouvez une faille,
merci de **ne pas ouvrir d'issue publique**.

Utilisez la fonction « Report a vulnerability » de l'onglet Security de ce dépôt GitHub (signalement privé), en
décrivant la version, le scénario et, si possible, une requête qui reproduit le problème.

Le module est une version bêta : seule la dernière version publiée reçoit des corrections.
